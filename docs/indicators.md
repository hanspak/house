# 대시보드 지표 정의

주간 아파트 국면판(`index.html`)과 월간 주택 시장판(`monthly.html`)에 나오는 숫자가 어떻게 계산되는지 정리합니다. **KB가 발표한 값**과 **이 대시보드가 계산한 값**을 구분해 표시합니다. 계산한 값은 참고용이며 KB 공식 지표가 아닙니다.

계산 코드는 [scripts/market_analysis.js](../scripts/market_analysis.js)에 모읍니다. 화면 코드는 주간은 [scripts/dashboard_template.html](../scripts/dashboard_template.html), 월간은 [scripts/monthly_template.html](../scripts/monthly_template.html).

## 공통

| 항목 | 정의 |
|---|---|
| 가격지수 | KB 발표값. 기준 2026-01(주간 2026-01-12) = 100. 같은 기준이라 지역·유형끼리 흐름 비교는 되지만, **지수 높이로 가격 수준을 비교할 수는 없음** |
| N주(개월) 상승률 | 계산값. `(이번 값 ÷ N주 전 값 − 1) × 100`. 주간은 추석·설 주에 KB 조사가 빠져 14일 간격이 생길 수 있으며, 그 경우에도 '자료상 N번째 이전 주'와 비교 |
| 2021~22 고점 | 계산값. 2021-01 ~ 2022-12 구간 매매(또는 전세)지수의 최댓값과 그 주 |
| 고점 대비 | 계산값. `(이번 값 ÷ 고점 − 1) × 100` |
| 매매/전세 전환 | 화면 위쪽 버튼. 가격을 쓰는 화면이 모두 매매지수 또는 전세지수로 바뀜 |

## 주간 아파트 국면판

| 항목 | 정의 |
|---|---|
| 국면 | 계산값. 선택한 상승률 기간(기본 12주) 기준으로 다음 순서로 판정 |
| | ① 고점 아래 + 상승률 ≥ 상위 지역(시·도) 평균 → **고점 아래 · 빠른 회복** |
| | ② 고점 아래 + 0 < 상승률 < 평균 → **고점 아래 · 완만한 회복** |
| | ③ 고점 아래 + 상승률 ≤ 0 → **고점 아래 · 약세** |
| | ④ 고점 위 + 상승률 ≤ 0 → **고점 위 · 상승 멈춤** |
| | ⑤ 고점 위 + 상승률 ≥ 평균 → **고점 위 · 상승 가속**, 그 외 → **고점 위 · 상승 둔화** |
| 이번 주 요약 · 고점 돌파 | 계산값. 12주 전에는 고점 아래였는데 이번 주 고점 이상인 하위 지역 |
| 이번 주 요약 · 상승/하락 전환 | 계산값. 4주 상승률의 부호가 4주 전과 비교해 바뀐 하위 지역 |
| 주간 변동률 열지도 색 | 계산값. 전주 대비 %. 색의 최대치는 화면에 보이는 값의 95% 백분위(최소 ±0.1%) |
| 상승 확산도 | 계산값. 하위 지역 중 그 주에 지수가 오른 지역 비율(%)의 4주 이동평균. 하위 지역이 2곳 미만이면 계산하지 않음 |
| 상승률 순위 변동 | 계산값. 4주마다(최근 28주, 8개 시점) 선택 기간 상승률로 순위를 매김. 8개 시점 모두 값이 있는 지역만 포함 |
| 매매·전세 동행 지도 | 계산값. 선택 기간 매매 상승률(세로)과 전세 상승률(가로). 대각선 아래 = 전세가 더 오름(매매·전세 차이 축소) |
| 심리지수 | KB 발표값(중개업소 설문, 0~200, 100 = 중립): 매수우위, 매매거래활발, 전세수급, 전세거래활발. 시·도 단위까지만 있음 |
| 심리 백분위 | 계산값. 2003년 이후 모든 주 가운데 이번 주 값보다 낮았던 주의 비율. 80 이상 '높은 편', 20 이하 '낮은 편' |
| 시·도 심리 지도 | KB 값. 가로 매수우위지수, 세로 전세수급지수. 흐린 점은 12주 전 위치 |
| 심리가 가격을 앞서는가 | 계산값. 2008년 이후 매주 (그 주 심리지수, 이후 12주 상승률)을 점으로 찍고, 심리지수 10 단위 구간별 중앙값(표본 15주 이상 구간만, 짝수 표본은 상위 중앙값)을 선으로 연결. 매매는 매수우위지수, 전세는 전세수급지수와 비교. 결론 문장은 이번 주 값 ±5 이내였던 과거 주들의 중앙값(짝수 표본은 상위 중앙값)과 상승 비율 |
| 상승 사이클 저점 | 계산값. 앞뒤 52주 안에서 가장 낮은 주이면서, 이후 104주 안에 3% 넘게 오른 주. 저점 사이 간격은 52주 초과. 최근 5개까지 표시 |
| 지역 비교 차트 | 계산값. 고른 지역(최대 4곳)을 기준 시점 값 = 100으로 다시 계산. 기준은 시·도 고점 주, 1년 전, 3년 전, 2024-01 첫 주 중 선택 |
| 월간 지표 (선택 지역 상세) | 월간 주택 시계열에서 가져온 KB 값. 전세가율은 해당 하위 지역 값이 없으면 시·도 값 |

## 월간 주택 시장판

| 항목 | 정의 |
|---|---|
| 유형별 지수 | KB 발표값. 종합·아파트·단독·연립 매매/전세지수(2026-01 = 100). 연립 지수는 시·도 단위까지만 있음(구 단위는 KB가 0으로 비워 둠 → 자료 없음 처리) |
| 평균·중위 가격 | KB 발표값(만원). 화면에서는 1억 이상이면 '억' 단위로 표시 |
| 아파트 전세가율 | KB 발표값. 매매가 대비 전세가 비율(%) |
| 5분위 가격·배율 | KB 발표값. 아파트 가격을 5등분한 각 구간 평균, 배율 = 5분위 평균 ÷ 1분위 평균 |
| 주택구매력지수(HAI) | KB 발표값. 100 = 중위소득 가구가 중위가격 주택을 대출받아 적정 부담으로 살 수 있음. 2018년까지는 개편 전 소득 기준 표, 2019년부터는 개편된 가계동향조사 기준 표를 이어 붙임 |
| 매매·전세 전망지수 | KB 발표값. 3개월 뒤 전망 설문. `100 + (크게상승 + 약간상승×0.5) − (크게하락 + 약간하락×0.5)`, 0~200 |
| 월세지수·전월세전환율 | KB 발표값. 수도권 6개 권역만. 전월세전환율 = 월세 × 12 ÷ (전세가 − 월세보증금) |
| KB 선도아파트 50 | KB 발표값. 매년 12월 시가총액 상위 50개 단지의 시가총액 변동 지수 |
| 오피스텔 | KB 월간 오피스텔 시계열(2011~). 매매지수, 평균 매매·전세가, 전세가율, 임대수익률(월세 × 12 ÷ (매매가 − 월세보증금)). 권역 11개, 면적별(초소형~대형)은 전국·수도권·서울·경기만 |

## 실거래·거래량·금리

| 항목 | 정의 |
|---|---|
| 실거래 | 국토부 실거래가 API(매매) 전국 원자료. 전국·17개 시·도·시군구 선택 가능. 계약일 기준, 해제 신고 거래 제외. 신고 기한(계약 후 30일) 때문에 **지난달·이번 달은 '집계 중'**이며 건수가 계속 늘어남. 수집 누락 월은 0건이 아닌 자료 없음으로 표시하고, 이를 포함한 상위 지역 집계도 비움 |
| 최근 3개월 | 계산값. 집계 중인 달을 뺀 가장 최근 3개월. 1년 전 같은 3개월과 비교 |
| ㎡당 중위 거래가 | 계산값. 거래마다 `거래가 ÷ 전용면적`을 구한 뒤 그 달(또는 3개월) 중위값. 3개월 중위는 해당 기간의 모든 거래를 합쳐 계산한 중위값 |
| 중위 거래가 | 계산값. 그 달 거래가의 중위값. 그 달 거래된 집의 지역·면적 구성에 따라 크게 흔들림. 월별 또는 3개월 가격 표본이 10건 미만이면 화면에서 가격과 가격 상승률 표시를 보류 |
| 소액 거래 목록 | 실거래가 1억·1.5억·2억 이하인 연립·다세대·오피스텔 거래(최근 12개월). **공시가격이 아님** — 공시가격 1억 이하 후보를 좁히는 용도 |
| KB 시세 vs 실거래 | 선택 시·도(또는 전국)의 KB 월간 중위 매매가(조사 시세)와 국토부 실거래 중위가. 시군구를 선택해도 이 비교는 해당 시·도 전체 기준. 오피스텔은 비교할 중위 시세가 없어 안내 표시. 둘은 정의가 달라 같은 값이 아님 |
| 부동산원 아파트 매매 거래량 | R-ONE (월) 행정구역별 아파트매매거래현황, 동(호)수. 전국·시·도·시군구 선택. 광주·전남 통합 이후 기존 권역의 공표값이 없으면 해당 권역 시군구를 모두 더함(한 곳이라도 누락되면 비움). 12개월 이동평균은 계산값 |
| 미분양 주택 | R-ONE 미분양주택현황의 시·도 '계'(호). 전국·수도권·지방은 계산값: 해당 시·도를 모두 더하되, **한 곳이라도 그 달 값이 없으면 합계를 비움**(과소 집계 방지). 세종처럼 자료 시작 전 달은 0으로 봄. 준공 후 미분양은 따로 없음 |
| 금리 | ECOS. 기준금리(722Y001), 예금은행 신규취급액 기준 대출금리(121Y006): 주택담보대출, 고정형·변동형 주담대, 전세자금대출 |
| 금리와 거래량 상관계수 | 계산값. 2015년 이후 전국 공통 월별 주담대 금리와 선택 지역 아파트 거래량(수준)의 피어슨 상관계수. 인과관계를 뜻하지 않음 |

전국 실거래의 시군구 수집 코드는 `scripts/trade_regions.json`에 관리합니다. 출처는 [행정표준코드관리시스템 법정동코드 전체자료](https://www.code.go.kr/stdcode/regCodeL.do?menuNo=101010100010)이며 2026-10-06에 확인했습니다. 시 아래 구가 있는 지역은 구 코드를 조회하여 상위 시와 중복 집계하지 않습니다. 최근 24개월을 비교할 수 있도록 인천 개편 전 코드와 광주·전남 기존 코드도 수집합니다. 전남광주통합특별시의 새 코드는 KB/R-ONE과 비교 가능한 광주·전남 통계 권역으로 연결합니다. 같은 지역의 개편 전·후 코드가 동일 거래를 반환하는 경우 코드 간 중복을 제거하되, 한 코드 안의 동일 행 여러 건은 보존합니다.

## 실거래 분석 확장 (분석 규격 2)

- 면적: 전체 / 60㎡ 이하 / 60㎡ 초과~85㎡ 이하 / 85㎡ 초과.
- 연식: 전체 / 5년 이하 / 6~20년 / 21년 이상. 수집연도에서 건축연도를 뺀 값이며 경과 개월을 계산하지 않는다. 전용면적·건축연도 미확인 값은 전체 조건에는 남기고 해당 조건 필터에서는 제외한다.
- 면적·연식 조건은 국토부 실거래와 소액 목록에 적용한다. R-ONE 거래량·회복률·미분양과 ECOS 금리는 조건 필터를 적용하지 않는다. KB 비교는 조건이 다른 가격을 직접 비교하지 않도록 전체 조건에서만 제공한다.
- 최근 3개월 가격: 해당 3개월 원거래를 합쳐 계산한다. 월별 중위값의 중위값이 아니며, 어느 한 지역·월이라도 수집 누락이면 상위 집계 및 해당 3개월 비교를 비운다.
- 가격 표본: 양수인 거래금액을 가진 거래. ㎡당 가격 표본은 여기에 전용면적도 양수인 거래만 포함한다. 거래 건수와 가격 표본 수는 구분한다.
- 가격 표시 기준: 해당 월·3개월 가격 표본 10건 이상. 10건은 대시보드의 표시 정책이며 통계적 신뢰를 보장하지 않는다. 조건을 좁혀도 입지·단지·층 구성 차이는 남는다.
- 가격 분포: 3개월 원거래 가격의 하위 25%, 중위, 상위 25%. 분위값은 정렬한 관측치 위치 `(n-1)×p`를 선형 보간한다. 이 구간은 신뢰구간이 아니다.
- 아파트 거래 회복률: 집계 중인 달을 제외한 R-ONE 최근 3개월 합계 ÷ 직전 5년의 같은 3개월 합계 평균 × 100. 과거 3개월이 모두 있는 기간만 사용하고, 최소 3개 과거 기간을 요구한다. 비교 평균이 0이면 계산하지 않는다. 분모의 실제 기간 수와 비교 기간을 함께 표시한다.
- 자료 기준일: 국토부, R-ONE 거래량, 미분양, ECOS, KB를 따로 표시한다. 표의 최신 기간은 해당 자료 전체에서 값이 존재하는 가장 최근 기간으로 지역별 가용 기간과 다를 수 있다. KB 월간 수집일은 기존 기록이 없어 임의로 추정하지 않는다.

계산 구현은 `scripts/trade_analysis.py`에 있다. 분석 규격이 다른 집계 캐시는 사용하지 않는다. 조건별 집계 JSON은 화면에서 선택할 때 읽으며 각 파일명에 내용 해시를 붙여 이전 자료와 섞이지 않도록 한다.

## 관심 지역 시장 종합

종합 화면(`overview.html`)은 아파트 전체 면적·연식 기준이다. 지표별 기간·권역을 함께 표시하며 여러 지표를 임의의 투자 점수로 합산하지 않는다.

| 지표 | 정의 |
|---|---|

| 실거래 중위·거래 회복률 | 실거래 분석 규격 2의 아파트 전체 조건 집계와 R-ONE 회복률을 사용 |

## 자료 변경 이력

`overview.html`의 **자료 변경 이력**은 국토부 매매(아파트·연립다세대·오피스텔 전체 조건), 아파트 전월세, 공식 미분양의 공개 월별 집계를 비교한다. 개별 계약의 수정 이력이나 KB·R-ONE·ECOS의 이력은 제공하지 않는다.

- 같은 지역·같은 월·같은 지표가 연속된 완전한 수집 사이에서 바뀐 경우만 기록한다. 새 월의 첫 발표와 조회 기간에서 제외된 월은 변경으로 세지 않는다.
- 이전 값·현재 값·차이·단위·자료 기준월·두 수집일을 표시한다. 두 값이 모두 숫자일 때만 차이를 계산한다. 자료 없음 → 숫자는 자료 보완, 숫자 → 자료 없음은 표시 보류다. 매매 가격 표본 10건 미만은 이전·현재 모두 표시 정책을 적용한다.
- 매매·전월세는 현재 수집기가 재조회하는 최근 3개월 중심으로 변경을 확인한다. 더 오래된 월은 캐시를 재사용하므로 추후 정정을 매번 탐지하지 못한다. 공식 미분양은 추적 범위 최근 6개월 파일을 매 수집 다시 읽는다.
- 신고 추가·해제·정정·자료 보완 등을 변경 수치만으로 구분할 수 없어 원인을 단정하지 않는다. 신고 추가를 거래량 증가의 시장 신호로 바로 해석하지 않는다.
- 2026-10-08에 현재 집계를 비교 기준으로 등록했다. 이전 기간의 이력을 만들어 넣지 않는다. 원자료 수집일도 유지한다. 이후 완전한 수집부터 비교 기록이 쌓인다.
- 자료별 최근 변경 수집 12회 및 변경 값 최대 20,000개를 보존한다. 한도를 넘으면 오래된 기록부터 줄이고 생략 여부를 표시한다. 전국·시도·시군구 합계의 변경은 별개 기록이므로 변경 값 건수는 고유 계약 건수가 아니다.
- 수집 캐시에 이력을 함께 보관한다. 캐시가 소실되면 커밋된 기본 집계를 다시 비교 기준으로 사용하므로 전체 기간의 영구 감사 기록을 보장하지 않는다.
- 선택 지역과 자료별 필터, 20행씩 더 보기, 표시 범위 전체 CSV를 제공한다. 화면은 내용 해시를 붙인 이력 JSON을 요청 시 읽는다. 현재는 초기 비교 기준이므로 실제 변경 기록이 없을 수 있다.

## 공급 단계·입주예정

- 아파트 인허가·착공·준공: 국토부 공식 주택건설실적 파일의 **아파트 월계** 열. 누계 값을 월 실적으로 표시하지 않는다. 최근 6개월, 전국·공표 시도 합계 교차 점검. 자료는 [인허가](https://stat.molit.go.kr/portal/cate/statMetaView.do?hRsId=31), [착공](https://stat.molit.go.kr/portal/cate/statMetaView.do?hRsId=471), [준공](https://stat.molit.go.kr/portal/cate/statMetaView.do?hRsId=468)다. 인허가·착공·준공은 동일 사업 집단이 아니므로 더하거나 빼서 미래 입주량으로 환산하지 않는다. 준공 실적은 정비사업의 기존 주택 철거를 차감한 순증 공급도 아니다.
- 입주예정: [한국부동산원·부동산114의 공식 공동주택 입주예정물량](https://www.data.go.kr/data/15111714/fileData.do) CSV. 현재 기준일 2026-06-30, 전망 2026-07~2028-06, 30세대 이상 공동주택 703개 항목이다. 일정 변경·후분양 등으로 전망이 달라질 수 있으며 실제 입주 확인 자료가 아니다.
- 향후 6·12개월: 화면 생성 기준월(KST)을 포함해 해당 기간의 **예정월이 기재된 물량**을 합산한다. 이번 달은 아직 입주하지 않은 잔여 물량만을 뜻하지 않는다. 기간이 공식 전망 범위를 넘거나 자료가 불완전하면 합계를 비운다.
- 예정월 `YYYY-00`: 연도만 알려진 월 미정 물량이다. 연도별로 별도 표시하고 월별 그래프와 6·12개월 합계에 넣지 않는다. 전국 현재 월 미정 2027년 386호를 포함한 전체 공식 자료 합계는 425,412호다.
- 지역 범위: 공급 실적은 시도까지만 제공하므로 시군구에서도 시도 권역임을 표시한다. 광주·전남 개편 이후 실적은 통합 공표값으로 표시하고 임의 배분하지 않는다. 입주예정은 공식 주소의 시군구를 정확히 연결할 수 있는 경우만 시군구 집계를 제공한다. 인천 개편 전 중·동·서구 등 주소가 불확실하면 해당 시도 전체로 대체하고 이유를 공개한다. 주소 미확인 물량을 특정 구의 0호로 처리하지 않는다.
- 그래프·표: 6개월·12개월·전체 전망 선택. 과거 예정월은 과거 예정치로 표시하며 준공 실적으로 바꾸지 않는다. 공급·예정 CSV에는 지표·기준월/예정월·공식 전망 기준일·실제 표시 권역을 포함한다.
- 변경 이력: 두 자료 모두 기존 변경 이력 저장기를 사용한다. 월 미정 변화는 `YYYY-00`으로 보존한다. 각 수집은 공식 자료를 다시 읽고 검증을 통과한 집계만 교체한다. 초기 집계는 추적 기준 등록이며 소급 이력은 만들지 않는다.

## 임대차 표본·계약 구분 비중

- 순수 전세 표본은 월세 0·양수 보증금, 월세 표본은 양수 월세 계약이다. 중위 가격은 해당 표본 10건 이상에서만 표시한다. 두 표본의 합이 전체 계약과 항상 같은 것은 아니다.
- 확인 계약 중 갱신 비중 = 갱신 ÷ (신규 + 갱신) × 100. 미확인 계약을 분모에서 제외한다. 확인 계약이 0건이면 비운다. 전세·월세 합계의 구분 기준이며 시장 전체 갱신율이 아니다.
- 전체 중 미확인 비중 = 미확인 ÷ 전체 계약 × 100. 전체가 0건 또는 수집 누락이면 비운다. 갱신 비중과 함께 구분 정보 제공 범위를 확인한다.
- 최근 2개월은 수집월 기준 집계 중 표시한다. 대표 가격 카드는 이 기간을 제외한다. 보증금·면적·연식·입지 구성은 보정하지 않는다.

## 실거래 거래 구성 변화

- 선택 지역·유형의 전체 면적·연식 거래를 대상으로 한다. 화면의 면적/연식 필터와 별도이며 최근 신고 집계 중인 달을 제외한 3개월과 전년 같은 3개월을 비교한다.
- 면적 3구간·미확인, 연식 3구간·미확인을 각각 표시한다. 구간 거래 건수 ÷ 해당 유형 전체 거래 × 100으로 비중을 계산한다. 면적과 연식은 별도 분류로 서로 합산하지 않는다.
- 미확인 건수 = 전체 건수 − 해당 분류의 확인된 3개 구간 건수. 미확인을 확인 구간에 재배분하지 않는다. 각 기간은 월별 비중을 평균하지 않고 3개월 거래 건수를 합쳐 계산한다.
- 비중 변화 = 최근 비중 − 전년 비중(퍼센트포인트). 전체 0건·기간 부족·누락·구간 합계 불일치면 비중/변화는 보류한다. 실제 0건은 유지한다. 화면 반올림 때문에 표시 비중의 합이 100%와 조금 다를 수 있다.
- 연식 분류는 게시 자료의 수집연도에서 건축연도를 뺀 기존 기준을 두 기간에 동일 적용한다. 전년 계약 당시 연식이나 동일 주택 반복거래 비교가 아니다.
- 전체 조건 ㎡당 중위가격도 함께 표시하며 실제 3개월 거래를 합친 값과 10건 표본 표시 정책을 적용한다. 구성 변화는 가격 변화의 원인을 확정하거나 가격을 보정한 지수가 아니다. 단지·입지·층 구성 차이가 남는다.

- 지역 구성 비교는 전국에서 17개 시도, 시도/시군구에서 해당 시도의 시군구를 대상으로 한다. 지역·분류마다 4구간(미확인 포함) 중 비중 변화 절댓값이 가장 큰 구간을 표시하고 변화 폭 내림차순으로 정렬한다. 동률이면 기존 구간 순서의 첫 구간을 표시하며 모든 변화가 0이면 특정 구간을 선택하지 않는다.
- 최근·전년 전체 거래 건수가 각각 10건 이상일 때만 지역 간 비교를 표시한다. 구간 자체의 10건 기준이나 통계적 유의성 기준은 아니다. 기준 미달·누락·구간 합계 불일치는 비교를 보류하며 실제 전체 건수와 사유를 유지한다. 미확인 비중 변화는 자료 기재 범위 변화도 반영할 수 있다. 투자 순위나 가격 변동 원인으로 해석하지 않는다.
- 지역 비교 CSV는 화면 순서와 같은 구간·기간·전체 건수·구간 비중·변화·보류 사유·비교 기준·연식 기준연도·수집일을 제공한다. 보류 값은 빈칸, 실제 변화 0은 0이다. 지역 이름으로 상세 거래 구성에 이동한다.

- 월별 거래 구성 추이는 게시된 24개월의 각 월 전체 거래 건수를 분모로 면적/연식 4구간의 비중을 계산한다. 3개월 합계 비중과 달리 월별 관측값이며 이동평균·과거값 이월을 사용하지 않는다. 전체 거래 0건·누락·구간 합계 불일치는 그래프의 빈 구간으로 유지한다. 고립된 유효 월도 점으로 표시한다.
- 월별 전체 거래 1~9건에서는 실제 비중을 유지하고 변동 주의를 표시한다. 이는 지역 간 최대 변화 비교의 양기간 10건 기준과 별개이며 가격 표본 기준을 변경하지 않는다. 신고 집계 중인 최근 달은 그래프 음영·표/CSV 신고 상태로 구분한다. 그 외 월도 후속 신고·정정으로 바뀔 수 있다.
- 월별 표/CSV는 계약월·분류·구간·전체/구간 거래 건수·비중·자료/신고 상태·연식 기준연도·전체 조건·실제 수집일을 제공한다. 그래프는 면적/연식 필터와 별도인 전체 조건이며 연식은 두 기간 비교와 같은 고정 기준연도를 사용한다.
